# Module 1 – Job-Market Data and Skill Vocabulary

## Contents
This folder contains the processed datasets, unified skill vocabulary,
alias mappings, preliminary role skill profiles, gold-set review candidates,
and the Module 1 final report.

## Raw datasets
The original O*NET, ESCO, and Kaggle datasets are maintained separately
in Google Drive because of their large file sizes.

Google Drive location:
Career_Intelligence_Project/Module_1/01_Raw_Data/

Raw datasets are not included in this Git repository.

## Important note
The gold-set file contains candidates pending manual review.
The role skill profiles are preliminary and require validation.
